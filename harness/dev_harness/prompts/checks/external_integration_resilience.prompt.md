Does this diff touch how the Workbench calls, or receives data from, an external system (Mock Systems through IMockSystemsClient, the Data Ingestion Layer, the committee push-back of risk flags, any new HttpClient or outbound call, or any new inbound endpoint called by an external system)? This project's rule is that a Mock Systems outage must never fail intake or a committee vote. Flag: (1) a call to the external system that can fail intake or a vote: an outage, timeout, non-2xx response or malformed body must be caught and logged without blocking the change request or the vote (note that catching only HttpRequestException misses timeouts, which surface as TaskCanceledException, and bad JSON, which throws JsonException); (2) an outbound call with no timeout or no CancellationToken; (3) external data stored or used without validation (nulls, missing fields, unexpected or oversized values), or placed into a prompt, SQL or HTML as if it were trusted; (4) downstream code (scoring, AI prompts, committee, UI) reading live external data instead of the immutable snapshot stored at ingestion; (5) a new inbound endpoint for an external caller that is unauthenticated or can read or write internal tables beyond its one purpose.
